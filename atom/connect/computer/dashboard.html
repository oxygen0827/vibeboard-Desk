开始使用

按顺序完成，ATOM 就能和这台电脑一起工作

    最近活动

    模拟设备

    在这台 Mac 上运行 ATOM 小电脑和全部应用

    在小电脑「设置 → 数据与恢复」开启同步
    模拟设备未启动点「启动」后，屏幕会显示在这里。

    设备与连接

    这台电脑和 ATOM 通过同一个 ATOM 服务连接

    ATOM 服务

    未配置

    更换服务器后需要在 ATOM 上重新配对。任务内容经中继转发，请使用你信任的服务器。

    已配对设备

    你账号下的 ATOM

    用配对码连接

    连接别人的 ATOM，或账号下没有显示时使用
    1. 在 ATOM 上打开「我的电脑」，生成配对码
    2. 在这里输入配对码
    3. 回到 ATOM 确认配对

    任务

    ATOM 发来、在这台电脑上执行的任务

    Agent

    使用这台电脑上已登录的开发工具执行任务

    准备 Codex

    安装官方 Codex CLI，在终端运行 codex login，完成后点「重新检测」。ATOM Connect 会创建独立会话，不接管已打开的 Codex 窗口。

    Claude Agent（可选）

    需要官方 SDK 和 ANTHROPIC_API_KEY 环境变量。
