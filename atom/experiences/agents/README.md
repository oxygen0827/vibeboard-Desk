# Agent 小屋

任务伙伴已整合进 Agent 小屋，设备与市场保留一个入口。原创 Canvas 等距像素工作室依据真实任务状态变化，空闲、审批、完成与失败均有明确区分。

- 按电脑筛选；翻页或“关注此任务”固定一个任务，取消关注后自动优先显示待审批、执行中和排队任务。
- 使用 AtomApp 保存电脑与任务偏好，重进后恢复；保存失败可重试，读取失败不会覆盖既有记录。升级时 shell 仅在 Agent 小屋还没有记录时读取原任务伙伴的关注项，已有小屋记录优先。
- 显示实际最近回传时间；网络或电脑离线后保留最后一次状态，标注“上次状态”，暂停工作动画，不推测完成。
- “查看任务”进入“我的电脑”的真实任务详情，继续审批、预览或安装作品；“新任务”直接打开任务输入。电脑 Studio 的活动仅显示摘要并提示在电脑端查看，不将活动 ID 当成可打开的设备任务。
- 保留全屏、分页、语义图标和原桌面位置，没有页面滚动或常驻系统栏。

需要 manifest task-state 能力和用户首次授权。权限拒绝后停止自动请求，用户点刷新才重试。点击任务进入系统已有「我的电脑」查看/确认/接收作品；小屋不直接执行命令。

构建 `python3 atom/experiences/agents/build.py`。240×180 Canvas，最高10fps，减少动态效果关闭动作，退出释放动画和定时器。测试 `node atom/experiences/agents/ui.test.cjs` 覆盖电脑筛选、优先级、稳定关注、断线、任务跳转、保存/读取失败、旧偏好迁移和退出清理。

## 感知小屋（2026-10-31）

默认进入安静的小屋，右上角「任务」保留既有电脑选择、关注、确认与详情跳转。任务页左上角先回小屋，根页面回原桌面；所有按钮为共享五向运行时的语义控件。

通过 `AtomApp.sensors.subscribe` 获取系统标准事件；未知/未连接不能解释为无人。未装传感器时提供明确标注的「体验离开 / 回来」「轻轻摇一摇」手动演示。它们只影响场景，不生成完成记录。真实任务完成的画面仍只来自真实 task-state。

当前灰板尚未确定存在/惯性传感器型号，真实接线、精度、手持方向、抖动与温度/功耗均待真机验收。浏览器 fixture 仅证明事件和 UI 契约。

验证：`node atom/experiences/agents/ui.test.cjs` 保留旧任务回归；`node atom/experiences/agents/sensors.test.cjs` 验证真实共享五向运行时、传感器缺失/演示/恢复、分层返回与退出解绑。首页截图可在 ATOM Connect → 我的创作 → 首页截图上传；发布前使用真实界面审核封面。
