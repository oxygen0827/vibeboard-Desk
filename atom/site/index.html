先了解这几件事。

必须一直连着个人电脑吗？

不需要。已安装且资源完整的本地应用、已保存的创意作品可以独立运行。市场、同步和模型生成需要联网；只有执行个人电脑上的 Agent 任务，才需要电脑开机并运行 ATOM Connect。

不会写代码，也能开始吗？

可以从现有应用开始，也可以在工作坊描述需求，让模型生成一个应用。先预览、检查交互，再确认安装。复杂作品仍可能需要多次修改或开发者帮助，生成服务需要配置有效模型。

现在可以体验到什么？

当前是可运行的研发原型，包含桌面、工作坊、源码市场、电脑配对及本页介绍的创意应用。样机使用鼠标与键盘；触屏、实体 Home 键及短片中的部分传感器玩法属于后续硬件方向。设备上没有部署大型语言模型。

从哪里开始使用和参与开发？

已有设备请打开使用指南，从开机、账号、配对到创作逐步开始。开发者可进入公开仓库的 deploy/ldcx-public 分支查看源码、构建电脑伴侣或部署服务。当前没有公开公证的电脑端安装包。
