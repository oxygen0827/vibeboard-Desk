ATOM 使用手册

从开机，到你的第一个作品。

先独立体验，再连接电脑。按需要配置账号、模型与应用，一步步把 ATOM 变成你的创作终端。

没有匹配内容。试试“电脑”“安装”或清空搜索。

01 / 第一次使用

  1. 开机并进入 ATOM 桌面。 当前样机由 Debian 启动全屏桌面，使用鼠标与键盘；下一版触屏和实体 Home 键尚未作为本版硬件交付。
  2. 检查网络和声音。 顶部状态栏可以查看网络与电脑连接状态。在设置调整音量、背光；联网服务需要有效网络。
  3. 先打开一个本地应用。 试试声音实验室、像素实验室或已安装的图形作品。它们无需先配对个人电脑。
  4. 需要同步和市场时，登录账号。 设备与电脑使用同一个市场账号；电脑连接配对是另一项授权，需要单独完成。
  5. 第一次创造。 进入工作坊，配置有效模型服务，输入一个简单需求，生成后先预览，再明确安装到桌面。
三件事相互独立：市场账号管理作品与同步；设备配对授权电脑任务；模型账号/API Key 提供生成或语音能力。登录其中一个，不代表其余已配置。

02 / 桌面与操作

点击图标
全屏打开应用；应用内不保留永久系统顶栏和底栏。
滚轮 / 拖动
左右翻桌面页面；也可用左右方向键。底部圆点随页面移动。
点击页码
打开页面总览，直接跳到目标页。
短按空格/Home
从应用返回打开它时所在的桌面页；已经在桌面时回到第一页。文本输入框中保留正常空格输入。
长按空格
约 650 ms 唤醒录音，松手结束；在支持的页面中转写到输入框，发送/生成仍需确认。
长按图标
按住鼠标左键 600 ms 打开应用操作菜单；移动会取消长按。卸载需要再次确认，内置保护应用不可卸载。

新安装应用排在桌面最后；更新保留原来的位置。常规页面固定一屏，只有正文、长列表、源码与结果等内容区域可以滚动。

03 / 账号与恢复密钥

  1. 在应用市场或电脑 Studio 登录/注册。用户名为 3–32 位字母、数字、下划线或连字符，密码至少 12 位。
  2. 进入账号设置，绑定邮箱，填写邮件中的 6 位验证码。邮箱验证后才能使用邮件找回密码；发送能力取决于服务器邮件配置。
  3. 第一次启用便签/今日加密时，会显示一次恢复密钥。抄写或存进密码管理器，确认已保存。
  4. 新设备使用同一账号登录，并按照界面要求解锁加密数据。账号密码和恢复密钥不要发给 AI，也不要写进应用源码。

忘记密码怎么办？

在登录页选择“忘记密码”，通过已验证邮箱的验证码重置。改完密码后，旧的加密便签和日程仍需要恢复密钥才能解开。 邮件找回账号并不能替代数据恢复密钥。

没有恢复密钥时，服务器不能帮你解密旧内容。界面的“放弃旧内容”会删除无法解密的旧记录；只有明确放弃后再操作，不要把它当作普通重试按钮。

04 / 连接个人电脑

电脑端 ATOM Connect 是连接与创作控制台。服务器负责双方通信；真正执行项目任务的，是你个人电脑上的 Agent。

获取 ATOM Connect

当前提供 macOS 开发版构建脚本，以及可跨平台运行的 Node.js 源码。尚无公开公证的 macOS 安装包或 Windows 原生安装包，请从源码构建，不提供虚假的下载按钮。

查看电脑伴侣构建与运行说明 ↗

# 先安装 Node.js 24+，在仓库根目录运行
node atom/connect/computer/main.mjs --port 8788
# 浏览器打开 http://127.0.0.1:8788/

配对的完整顺序

  1. 电脑端：打开 ATOM Connect，在设备与连接设置中填写服务器地址 https://ldcx.tech/atom，设置电脑名称并保存。
  2. 授权项目：添加允许 Agent 处理的本地文件夹，选择合适的只读/可写权限。不要一次授权整个磁盘。
  3. 小电脑：打开“我的电脑”→连接设置，填写相同服务器地址，保存并生成配对码。
  4. 电脑端：在有效期内输入配对码，再回到小电脑确认显示的电脑名称。仅输入配对码不等于完成授权。
  5. 核对身份：双方界面显示的 6 位安全码应一致；密钥变化或不一致时停止任务，重新核对并配对。
  6. 发起任务：在小电脑选择在线电脑、授权项目和可用 Agent，输入需求，确认发送。需要审批时手动允许或拒绝。

在 Agent 小屋关注任务

任务伙伴已整合进 Agent 小屋。可以选择电脑、关注某个任务，并查看最近回传时间；取消关注时优先显示待确认和进行中的任务。离线会保留并标注上次状态。点击“查看任务”进入我的电脑处理审批或查看作品，“新任务”打开输入页面。电脑 Studio 的创作活动请在电脑端查看。

哪些情况下电脑必须在线？

调用电脑 Agent、编辑本地项目、电脑侧 AI 整理需要电脑开机、联网，且 ATOM Connect 持续运行。关上控制台窗口不一定退出菜单栏进程；让电脑休眠会使任务无法继续。设备本地应用不受影响。

ATOM Connect 管理自己的 Agent 会话，不接管已经打开的 Codex 桌面聊天。先在电脑按官方方式安装并登录 Codex CLI；其他适配器是否可用，以控制台实际检测结果为准。

05 / 创建你的应用

从设备工作坊开始

  1. 进入工作坊，在模型配置中设置生成服务的地址、模型名称和自己的有效 API Key。语音转写与播报是独立设置。
  2. 用文字描述，或按住空格说话，松手后检查转写。例如：“做一个海边呼吸计时器，有开始、暂停和每日记录。”
  3. 明确发起生成。界面显示排队、生成、检查等实际状态；网络/模型出错时查看原因，不连续重复提交。
  4. 生成后先预览。检查文字、交互、图标和屏幕适配；预览保存的数据是临时的。
  5. 确认安装，应用出现在桌面末尾。已有应用使用更新，不要通过卸载重装替代正常更新。

从电脑 Agent 创造

在“我的电脑”选择创建应用，让电脑 Agent 使用已授权的环境处理需求。任务产物通过校验后可以全屏预览，再确认安装。此路径与工作坊直接调用模型不同；大型 GitHub 移植仍需开发者处理完整资源与许可。

模型生成代码不等于功能已验证。安装来源不明的应用前，先查看源码、权限与许可证。录音转写不会自动发送电脑任务，也不会自动发布作品。

06 / 源码应用市场

市场不仅分享成品，也保留完整源码、版本和二次创作关系。公开作品的源码是公开内容，不能携带密钥、私人文件或账号数据。

  1. 发现：按分类或关键词浏览，查看作品说明、作者、许可证、版本及派生关系。
  2. 体验：先预览；合适时确认安装。更新保留桌面位置。回退仅回退应用资源，不把用户数据自动恢复到旧时间点。
  3. 继续创造：选择基于作品改造，得到自己的私有草稿。在电脑 Studio 编辑源码，或请 AI 修改。
  4. 检查：保存本地快照、比较修改，先测试预览；同步源码到自己的草稿。
  5. 发布：确认发布新版本。市场保留来源和许可；已发布版本不可变，新修改需要新版本。

如果某个应用需要便签、日程或任务状态能力，首次访问会请求授权。拒绝后应用应说明原因，不应假装已获取数据；可以在系统权限设置中撤销。

07 / 同步应用

在电脑上输入和整理，在小电脑上呈现与轻操作。两边登录同一账号后，随手记、今日待办与日程按账号同步；内容采用端到端加密，市场公开作品不加密。

离线与冲突

离线编辑先保存到当前设备，联网后再同步。看到“已保存在本机”不等于“已同步”。如果两端同时改了同一条内容，界面会提示冲突，可以保留双方版本或选择服务器版本。

AI 整理便签

在电脑 Studio 选中便签，发起整理，查看摘要与待办/日程建议。先检查时间、内容，再选择要应用的项目。AI 建议不会自动替你确认日程。

端到端加密保护传输与服务端存储；当你主动请求 AI 整理时，所选内容需要交给对应模型处理。设备 ID、时间、任务状态等运行元数据仍可被服务器看到。

相册：把照片带到桌边

电脑 ATOM Connect 和小电脑在应用市场登录同一账号。在电脑端相册导入 JPEG、PNG 或 WebP（单张最多 4 MiB / 1600 万像素）；小电脑可分页浏览、收藏与全屏轮播，电脑关闭后仍可联网使用。原图可在电脑端导出。

点「灵感」用文字创作，或在照片里点「改写」选择黏土、水彩、像素、胶片等风格。任务有真实状态，退出应用后继续执行；新作品独立保存，关联原照片并支持对比。需要管理员配置并开通火山方舟生图服务。若显示模型尚未开通，请在方舟控制台开通对应型号。

相册是账号私有云端存储，服务器可处理图片，当前不提供端到端加密或离线照片缓存；只有点击生成才将参考照片与描述交给模型服务。便签、今日和电脑任务原有加密方式保持不变。删除照片会同步到两端，需要确认。

08 / 语音与麦克风

长按空格开始，松手停止。录音最长 30 秒，转写后检查文本再发送。机器人应用提供语音聊天入口，具体对话能力依赖已配置的模型、转写和播报服务。

应用生成、语音转文字（ASR）、文字转语音（TTS）可以使用不同服务。密钥保留在设备的私有配置中，界面只应显示是否已设置。

声音听不清怎么办？

  1. 打开麦克风测试，先安静录制，再固定距离说同一句话，回放比较。
  2. 检查削波与电平，比较风扇开关、咪头位置和音量。界面电平是 dBFS，不是环境声压计。
  3. 录音期间系统可临时暂停风扇，但会受温度保护、超时和硬件支持约束；不能保证所有板卡都能关闭。
  4. 原型机咪头位于机壳内，风扇和结构传声会影响效果。不要把识别问题全部归因于云模型。

09 / 实验与运行边界

共生世界、语言炼金、合奏伙伴与 Agent 小屋已在 RK3566 样机运行，并已进入源码应用市场。前三个应用使用工作坊中配置的有效模型服务；Agent 小屋呈现已配对电脑回传的真实任务状态。

  • 语言炼金：输入画面描述，模型生成着色器，编译成功后替换画面。移动鼠标可以影响材质；当前不支持音频驱动。点击保存可保留作品。
  • 共生世界：描述建筑、天气或物件，由 AI 修改受支持的场景元素；可拖动旋转、切换昼夜天气。成功后确认保存，失败保留原世界。
  • 合奏伙伴：用鼠标琴键或 A S D F G H J K 弹奏，点击 AI 接奏，再播放和保存。这是基于音符的创作，不是原始录音转音乐。
  • Agent 小屋：选择电脑、关注任务，查看最新状态；离线保留上次状态并标注。审批和作品操作在“我的电脑”中完成。

生成任务退出应用后可能继续执行，但服务重启不会恢复内存中的任务。模型生成仍可能失败，不保证任意需求都能实现。查看四个体验的源码和验证记录。

当前样机基于 RK3566 / Mali-G52、480×360 屏幕和 Debian BSP。图形作品在设备本地渲染，模型任务可交给云服务或已配对电脑。没有在设备上部署大型语言模型，也没有当前可用的摄像头手势识别。

基础工具和完整安装的本地素材可离线；模型生成、ASR/TTS、市场与跨端同步需要网络。性能因作品复杂度而异，不承诺所有桌面 3D 项目都能直接移植。

10 / 遇到问题

电脑显示离线 / 找不到项目

检查电脑是否休眠、ATOM Connect 是否运行、两端服务器地址是否一致、配对是否被确认、项目是否已授权。身份密钥变化时重新配对。不要把本机 127.0.0.1 地址填给另一台设备。

一直排队或生成失败

区分设备工作坊任务和电脑 Agent 任务。前者检查模型 Key、额度、网络和模型名称；后者检查电脑在线、CLI 登录和审批。只根据实际终态判断完成；服务重启可能中断任务，不保证自动续跑。

保存了但另一端没有

检查是否同一账号、内容是否已解锁、是否仍有待同步提示或冲突。保留本地记录，先恢复连接，不要清缓存或用空白默认内容覆盖。

安装被阻止

市场安装按其确认流程进行；开发者导入或某些 Agent 产物安装可能需要设备开发模式。不要自动放开所有权限。大型移植需要完整资源，只有入口 JSON 不能保证运行。

页面黑屏或声音没停止

先短按 Home/空格返回桌面，再尝试重开；开发者检查应用生命周期与资源释放。持续黑屏请保留日志并联系维护者，不要直接重刷系统。

11 / 开发与协作

应用源码、设备后端、电脑伴侣与自托管平台位于同一个开放仓库。当前云部署相关代码在 deploy/ldcx-public 分支；协作前先核对团队采用的分支与最新 README。

git clone https://github.com/wangqioo/vibeboard-Desk.git
cd vibeboard-Desk
git switch deploy/ldcx-public
python3 atom/server.py

设备界面开发地址为 http://127.0.0.1:8770。本地启动不自带样机驱动、私有模型配置和个人数据。
