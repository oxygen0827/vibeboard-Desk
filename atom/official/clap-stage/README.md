# 掌心节拍

ATOM 原创桌面节拍器，40–200 BPM，3/4/6 拍、整拍或八分音符、木音/拍手/轻鼓三个合成音色。点四次中央数字可定速；开始后 Web Audio 提前调度音符，Canvas 只负责视觉，不用渲染帧决定发声时间。声音在用户点击开始后播放。

拍手定速是可选本机收音：先点击入口、再明确开启麦克风，先约一秒测底噪，再均匀拍手4–6次，最多20秒。此时停止节拍播放，避免扬声器回授；自动申请录音安静风扇模式，受现有温控保护约束。音频仅使用既有本机录音服务分析峰值/均方根和时间，不上传、不调用ASR。当前检测基于短时电平脉冲，拍手与其他突发声音不能绝对区分，风扇/结构噪声和距离会影响结果；点按定速始终可用。

设置通过 AtomApp 保存，读取失败禁用启动并提供重试。退出、后台或关闭麦克风页面时停止收音、音频、计时器与动画，风扇恢复自动。Space/Home 留给系统，不作为鼓键；空白区按 Enter 可点拍。预览可试听和点按定速，真实收音只在安装的设备应用中启用。
