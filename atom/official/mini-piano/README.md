# 迷你钢琴 · 采样版

五首完整钢琴作品：肖邦《夜曲 Op.9 No.2》《小狗圆舞曲》，德彪西《月光》，乔普林《枫叶拉格》，贝多芬《月光奏鸣曲》第三乐章。保留完整声部，替换旧版短旋律和套用和弦。

- 真实 Yamaha C5 / Salamander 采样，32 个离线样本、两档力度；首次操作显示音源准备状态，失败可以重试。
- 双手 / 右手 / 左手选择；表情开关；0.8 / 1 / 1.15 / 1.3 倍速，默认 1 倍。
- 表情模式为 ATOM 程序演绎：旋律突出、伴奏收敛、乐句强弱/速度呼吸与有限延音。不是录音演奏，也未声称复原原谱踏板。原谱模式关闭额外演绎，仍采用页面速度。
- 鼠标按住滑奏、触屏、数字 1–0、五向选择琴键后短按确认。长空格保留给系统语音。进入声部/速度选择后仍使用原生选择器。
- 切换曲目、声部、表情或速度会停止旧演奏；后三项在原本播放时从头重播。退出、失焦、隐藏、静音、取消手势均停止对应声音；暂停应用释放采样引用、音频与计时器。
- 每次最多 48 个发声节点；预排 200 ms 音频，播放不依赖动画帧。6 秒采样经过裁切与有损压缩，属于设备体积/音质折中，非完整 16 层音源。解码内存取决于浏览器采样率。
- 480×360 单屏、主题控件、应用内返回、有效独立 icon.svg；琴键黑白保持辨识度。

构建：`python3 atom/official/mini-piano/build.py`。随后运行图标 bundle 工具与 check_app。测试：`node atom/official/mini-piano/ui.test.cjs`。

素材的独立许可、署名、改动和原始 URL 见 SOURCE.md、asset-sources.json 和 licenses/。完整资源包含在文本 bundle 内，不依赖 CDN，也不需要密钥。生成市场首页封面时使用实际 UI：ATOM Connect → 我的创作 → 首页截图。
