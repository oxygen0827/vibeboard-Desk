# AI 进度灯 progress-light

把配对电脑上 AI 任务（Codex、Claude 等执行器，以及改造应用、整理便签）的真实状态放在桌边：

- 执行中：蓝色呼吸；排队：慢呼吸。
- 等你确认：琥珀色闪烁并提示音，确认要在电脑上或「我的电脑」里完成，本应用只读。
- 完成：绿色并轻响两声；失败或中断：红色，提示去电脑查看原因。
- 有新变化时显示「知道了」；多个任务可用左右按钮切换。

数据只来自系统 `atom:task-state`（任务状态、80 字以内的任务描述、更新时间），没有模拟任务或进度百分比。提示音只在两次真实读取之间观察到状态变化时响，打开应用时已完成的任务不会响。系统只提供任务描述，不提供执行结果摘要，所以完成后显示的是任务本身。

提示音开关通过 AtomApp 保存；读取失败时不覆盖原设置。减少动态效果时灯不呼吸、不闪烁，颜色与文字仍表示状态。退出时停止轮询并关闭音频。

`python3 build.py` 生成 `bundle.json`；`node ui.test.cjs` 运行浏览器测试。
