# 灰色板的四个小作品

将项目所有者 GrayOS 原型中的光子芯片、光子快跑、指尖烟花、迷你钢琴移到 ATOM 应用协议。每个应用的完整源码、用途图标、说明和许可都在相邻的独立目录中，`bundle.json` 可以从云端源码市场安装和改造。

| 应用 | 保留与改进 |
| --- | --- |
| 光子芯片 | 六条光路、相位变化、注入与探测器；计数为实际发生的路径交互，移除原来的模拟算力数字。它是交互示意，不是物理求解器。 |
| 光子快跑 | 点按 / Enter / ↑ 跃起，光门逐渐加速；最高纪录通过 AtomApp 保存，读取失败先重试，保存成功以确认结果为准。 |
| 指尖烟花 | 点击燃放、齐放、自动连放、最多八字的文字烟花；限制粒子数量，退出停止动画和音频。 |
| 迷你钢琴 | 十白键、七黑键、两种本机合成音色、小星星演奏；支持数字键、鼠标和指针输入。触屏硬件尚未实测。 |

共用控件使用系统白天 / 暗黑主题。黑白琴键、光路和粒子保留含义明确的场景颜色。每个应用为 480×360 全屏，无页面滚动、无常驻系统栏；空格 / Home 留给系统，退出返回打开应用时的桌面页。

旧的 GrayOS HTTP 轮询、蜂鸣服务、灯光接口、返回按钮已移除。应用不需要模型、账号或网络。退出释放计时器、动画和音频，页面隐藏时暂停；减少动态效果时不自动启动光流 / 烟花。

## 构建与验证

在仓库根目录运行：

```sh
python3 atom/official/gray-ports/build.py
python3 atom/tools/prepare_icon_bundles.py
node atom/official/gray-ports/test.cjs
```

测试启动临时的真实 ATOM 后端，以隔离 iframe 检查主题、布局、交互、最高纪录的读写与故障重试、声音、空格返回和生命周期释放。临时状态不接触用户设备的记录。真机迁移与显示栈边界见 [灰色板迁移记录](../../docs/gray-migration.md)。
