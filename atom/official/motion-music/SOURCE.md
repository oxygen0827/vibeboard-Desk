# Source and resource provenance

Original ATOM application. All graphics are locally rendered Canvas geometry;
all music uses locally synthesized sine tones in the C-major pentatonic scale.
No external pictures, fonts, sound samples, libraries or model credentials.
The physics engine is an intentionally bounded five-body simulation, not a fluid
solver. The ocean surface is a stylized visual response, not a physical liquid model.
No AI request is made by this application.
