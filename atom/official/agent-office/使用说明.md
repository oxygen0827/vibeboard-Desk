# 像素办公室 · 使用说明

你是老板，办公室里有四名像素员工。你说一个目标，他们在你配对好的电脑上**真的去做**，做完走过来向你汇报。

## 认识员工

| 员工 | 岗位 | 擅长 |
|---|---|---|
| 小序 | 协调员 | 理解你的目标，安排谁做什么，最后汇总 |
| 小研 | 研究员 | 阅读资料、比较信息、标明来源 |
| 小文 | 文案员 | 写作、总结、整理文档 |
| 小工 | 工程师 | 写代码和脚本、处理文件 |

名字可以在「连接与员工」里改。

## 操作

只用方向键和确认键就能操作：

- **方向键**：在工位、会议桌、资料柜和底部按钮之间移动。
- **确认**：打开选中的东西。老板会自己走过去，不用等他走完就能操作。
- **长按空格**：语音输入。转写完不会自动提交。
- **左上角返回**：退回上一页；在办公室里返回则回到桌面。

## 第一次使用（约 1 分钟）

1. 打开应用，系统会问"是否允许办公室派工"，选 **允许此应用**。
2. 点右上角的连接状态，进入「连接与员工」。
3. 依次选 **电脑 → 授权项目 → 执行器（Codex）**，然后点 **保存**。
4. 右上角显示"某某电脑 · 在线"就可以开工了。

> 电脑需要先在「我的电脑」/ ATOM Connect 里配对，并授权一个项目文件夹。
> 只想看看效果？在设置里打开 **演示模式**。演示模式用模拟数据，所有结果都标着"演示"。

## 派一个任务

1. 点底部 **派任务**（或走到会议桌），输入目标。例如：
   *"阅读资料 A 和资料 B，比较它们的结论，写一份简短说明。"*
2. 点 **拟定分工**。小序会真的想一想，屏幕上显示"正在拟定分工"。
3. 看分工方案：谁做、交付什么、要不要等别人。满意就点 **确认开工**；不满意就点 **修改需求**。
4. 员工回到工位开始工作。简单任务只派给一个人；复杂任务会安排先后顺序。
5. 做完后，员工**走到你面前汇报**，「汇报」按钮上出现红色未读数字。

想指定某个人做？选中他的工位，点 **交给TA**。

**每个人可以同时做不同的事**：小研在查资料时，你可以把另一件事直接交给小文或小工，互不等待。同一个人同一时间只做一件事，正在忙的员工按钮会显示“正在忙”。

## 看过程和结果

- **任务板**：每个人在做什么、在等谁、做完没有。还能 **停止目标**（按两次确认），或 **重试失败** 的部分。
- **工位**：选中员工可以看到他当前的真实状态和最新进展。
- **汇报**（或走到资料柜）：所有完成的工作都保存在这里。打开后按 ↓ 一段一段往下读。
  每份汇报包括：完成了什么、实际用了哪些资料、验证结果、还没完成的事。

## 让小工做个应用，并在小电脑上玩

想要番茄钟、计算器、小游戏这类**能直接打开用的东西**，就这样说：
*"做一个番茄钟。"*

1. 小序会把它交给小工，分工卡片上写着"交付一个应用"。确认开工。
2. 小工做完后打开他的汇报，顶部有两个按钮：
   - **试玩**：全屏打开这个应用试用。数据只是临时保存，按左上角返回会回到这份汇报。
   - **放到桌面**：系统再问你一次，确认后应用出现在桌面最后一页，之后就像普通应用一样打开。不想要了，长按图标卸载。
3. 以前的汇报里如果只有一段网页代码（比如"复制到 HTML 文件打开"），汇报顶部会出现 **做成应用**。点它，确认后小工会把这段代码改成正式的小电脑应用，做完同样可以试玩、放到桌面。

> 应用由电脑上的 AI 生成，不一定一次就满意：先试玩，觉得不好就换个说法再让小工做一次。

## 员工头上的标记

| 你看到的 | 意思 |
|---|---|
| 在工位敲键盘 | 正在真实执行 |
| 原地等待 | 排队中，或在等前一个人的结果 |
| 黄色 ！ | 需要你审批（比如要执行命令），选中他按 允许 / 拒绝 |
| 走到你面前 | 做完了，有新汇报 |
| 红色 ✕ | 失败了，打开任务板查看原因、决定是否重试 |
| "状态待同步" | 连接断了，状态暂时不能确认 |

空闲时员工偶尔会起身走走，这只是小动作，不代表在干活。

## 需要知道的

- 活是**电脑上的 AI** 在做，小电脑负责安排和查看。退出应用后，已经开工的任务会继续执行。
- 当前版本**不会改你的文件**，成果直接写在汇报里；应用也只装到小电脑上，不会写进电脑上的项目。
- 电脑最多同时做 3 件事（每名员工一件）。如果电脑上的 ATOM Connect 还是旧版本，它一次只能做一件，其余的会显示“电脑正忙，稍后自动派发”，排队等着，不需要你重试。
- 任务板会列出所有目标，每个目标有自己的 **停止**、**重试失败** 按钮。想到新点子但人都在忙？先 **保存草稿**。
- 如果没有联网搜索能力，研究员只用你项目里的资料，并会如实说明这一点。
