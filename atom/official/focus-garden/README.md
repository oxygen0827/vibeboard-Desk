# 专注花园

给一件事留出 5 / 25 / 45 分钟，时间结束后由用户点击「完成并种下」记录一株植物。真实计时不等于证明用户专注；人体存在信号只提供暂停建议，不自动暂停、不自动增加成长。

- 单屏 480×360，独立主题控件、植物图标、集成返回；无永久系统叠层。
- 开始、暂停、时长、结束及成长均等待 AtomApp.save 确认才更新已保存状态。失败保留原记录，重试；读取失败时禁止写默认值。
- 离开应用时释放计时器和传感器订阅；已保存截止时间继续计时，重新打开后仍需用户确认完成。
- 未连接传感器时完整支持手动操作；不要求账号、联网或 AI 调用。
- 当前最多绘制 18 株植物，累计成长总数不丢失。无签到惩罚、离开惩罚或伪造任务。

构建 `python3 atom/official/focus-garden/build.py`；静态检查 `python3 atom/tools/check_app.py atom/official/focus-garden/bundle.json`；浏览器验证 `node atom/official/focus-garden/ui.test.cjs`。测试覆盖共享五向启动、存储失败重试、读取保护、明确确认成长、存在感知只提示、退出解绑。真实传感器型号未确定，真实设备输入、图标、字体和功耗需单独验收。

在 ATOM Connect → 我的创作 → 首页截图上传真实应用首页作为市场封面；桌面图标与封面分开。不要把测试截图当作真实用户使用数据。
