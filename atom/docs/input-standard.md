# ATOM 五向输入强制规范 v1

状态：本分支新生成、新安装/更新、新发布应用的准入要求。实现说明见 [导航框架](five-way-navigation.md)。
本文是规范的权威来源；生成提示词、模板、自动校验与人工验收均须遵循本文。

## 1. 适用范围与操作

官方应用、工作坊生成应用、电脑 Agent 创作、GitHub 移植与市场新发布版本均适用。
键盘模拟使用方向键和空格键（Space），空格在文本框内同样保留给摇杆确认/语音；需要输入普通空格时可在语音转写或电脑端编辑。Home 保留兼容返回桌面。四方向移动焦点；中心键短按在松手时确认；长按 650 ms 唤起语音，松手结束。
焦点位于可编辑文本字段时直接语音输入，不自动发送、提交或覆盖选区外文字。
密码字段禁用语音文本写入。长按触发后禁止补发短按。
返回使用左上角可选中的按钮，逐层返回，应用根页面回原桌面页。
鼠标继续可用；不能将摇杆实现为必须精确瞄准的鼠标移动。

## 2. 必须声明的清单

```json
"input": {
  "version": 1,
  "profile": "five-way",
  "back": "root",
  "scene": "none"
}
```

- `version` 必须是整数 1；`profile` 必须为 `five-way`。
- `back=root` 用于单层应用；多级页面必须用 `custom` 并调用 `AtomApp.navigation.setBackHandler(...)`。
- `scene` 默认 `none`。包含 Canvas 时必须显式选择 `controls`（交互画布，提供 DOM 操作控件）或 `passive`（仅观看）。不得将有操作要求的画布伪报为 passive。
- 禁止自行添加“已认证”字段。声明是作者承诺，不是自动获得的操作验收证明。

## 3. 控件与布局 MUST

1. 所有核心操作都能只靠四方向和中心键完成，不能依赖悬停、拖动、右键或双击作为唯一入口。
2. 优先使用原生 button/input/textarea/select/a[href]。自定义点击控件必须具有准确 role、tabindex="0" 和可执行的 click 行为。
3. 焦点有可见反馈；隐藏、禁用控件不可进入；模态弹窗限制焦点范围并在关闭后恢复。
4. 左上角返回采用 iOS 风格的左箭头加上一级名称，当前页标题置于顶部正中且保留既有字号；不得把上一级名称放在右上角。系统页面由共享导航标题栏实现；应用应为返回控件及文字预留足够空间（基础箭头区域至少 48×48）。多级视图注册返回回调，不能依靠 history.back 猜测应用状态。
5. 核心页面保持单屏，仅必要的列表、长内容区域滚动，滚动后选中控件仍可见。
6. 不全局截获 Space/方向事件，不自行重复实现系统长按语音。Canvas/WebGL 的核心操作须暴露可导航 DOM 控件。
7. 使用 AtomApp 生命周期、保存确认和主题规范，返回后释放音频/计时/GPU任务。

## 4. 自动准入检查与真实验收

共享实现：`atom/app_input.py`，设备和服务器使用同一份代码。
自动检查：清单结构/版本、显式 Canvas 分类、交互画布的 DOM 控件存在性、明显缺少语义的 inline onclick、custom 返回回调的源码证据。
这些检查不执行任意源码，也不证明动态页面、全部画布操作或返回回调实际正确；源码中的同名字符串可能不足以代表真实实现。

真实操作验收必须覆盖：

- 480×360 下只用摇杆进入并完成主要流程、返回原桌面页。
- 列表边缘滚动、弹窗、删除项目及异步加载后的焦点落点。
- 文本语音输入保留内容、不自动提交；长按后松手不点击。
- 录音启动慢时先松手、断网、切换应用时正确结束并恢复风扇。
- 鼠标与摇杆切换、浅色/暗色焦点可读、退出释放资源。

## 6. 兼容与部署

已安装的历史应用、现有市场版本和旧草稿仍可读取，不因缺失声明而删除。
它们更新、重新安装或发布新版本时须补适配并通过检查。
模拟器与镜像构建器的仓库种子迁移可通过内部 `require_input=False` 接受缺失声明的历史应用；这是兼容例外，不表示通过五向验收。HTTP客户端没有该开关；存在但无效的声明仍会被拒绝。
不批量给第三方旧应用写入合规声明。官方种子应用完整导航适配作为后续迁移工作。

本分支规则尚未发布到真机、Mac发行包与云服务器。设备核心发布会包含 app_input.py；云端部署脚本也必须携带该共享模块。合并发布后强制门禁才会在线生效。

## 7. 共享焦点动效

焦点框由注入的 `input-navigation.js` 统一绘制，应用不复制动画代码、不覆盖 `#atom-focus-ring`。
标准控件及符合 role/tabindex 规范的自定义控件自动获得同一套效果：同页同范围移动与尺寸调整 140 ms，首次进入/切换范围淡入 100 ms，短按确认反馈 120 ms。
焦点与点击立即生效，动画不可阻塞操作；连续移动取消上一段动画并从当前可见位置继续。
每个文档只有一个选框，pointer-events:none，不参与导航和布局；鼠标操作、失焦、隐藏或移除目标时隐藏。
模态切换、页面重建采用淡入，避免选框横穿不相关界面；列表滚动后选框跟随控件。
尊重 prefers-reduced-motion，以及「设置 → 陪伴与交互 → 动画」；禁用动画时仍保留清晰的静态焦点框。
主题可提供 --atom-focus-color；默认使用当前主题的操作色。持续渲染不用于选框，位置跟踪只在短暂的交互动画窗口与滚动/尺寸事件中执行。
