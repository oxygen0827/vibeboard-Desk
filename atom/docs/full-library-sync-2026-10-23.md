## 可重复同步

在 Mac 仓库根目录运行（Python 需有 Pillow 等现有项目依赖）：

```sh
sh atom/tools/sync_full_library.sh
```

流程：严格生成完整种子 → 检查源文件中的私密文件/疑似凭据 → 生成确定性 ZIP 与截图索引 → 上传临时目录 → 校验 → 原子切换目录。

`build_full_library.py`、`promote_full_library.py` 与 `official/library-index.json` 是生成、发布及官网构建入口。`site/build_apps.py` 生成静态目录。Mac 打包继续使用 `connect/desktop/build-macos.py`。

封面按需读取，不把全部 Base64 图片塞进主目录响应；公网目录约 51 KiB，降低首次打开时的超时风险。服务器通过 `ATOM_LIBRARY_CATALOG` 指向索引，公开封面缓存只读，不写私人数据库。

## 空间与保留

没有创建 ECS 快照、数据库新备份或新的服务发布目录。每个应用只保留当前完整 ZIP；新目录校验成功后才清理本工具管理的旧 ZIP。不触碰其他文件或对象。

旧镜像只在逐文件与新 ZIP 完全相同（安装时间字段除外）时去重；有额外文件或差异时保留。本轮释放约 44 MB 重复资源，最终服务器可用空间约 744 MiB；本地/OSS 各三份备份限制继续生效。
