# ATOM 用户体验路线图

2026-10-22 用全新模拟设备（未联网配置、未登录）和全新 Mac 端，从开箱走完整流程后整理。核心问题：用户从开机到用上 AI 要独立完成 4 套配置（服务器地址、市场账号、电脑配对、模型 API Key），每一步都没有引导，出错时也没有去处。

按依赖和决策分四层，一层做完、验证后再进下一层。

## 第二层：产品决策已定（2026-10-22）

决定：桌面按我的方案；同账号自动发现；官方 AI 额度（智谱，Key 由用户写入服务器）+ 自带 Key。

| # | 事项 | 决定 / 状态 |
|---|---|---|
| 2.1 | 精简桌面：系统工具收进「设置」，首屏放招牌应用，合并重复应用（便签/随手记、任务伙伴、6 个「脸」类应用） | 完成：默认 8 页、一页一主题；系统工具收进「设置 → 系统工具」；重复与示例应用默认不显示，「应用管理」可逐个打开或恢复默认桌面 |
| 2.2 | 一个账号打通：设备和 Mac 登录同一账号后自动发现，免配对码，两边确认并核对安全码 | 完成：设备与 Mac 登录账号即自动连上服务并挂到账号下；Mac「设备与连接」与概览列出同账号的 ATOM，点「连接」后小电脑在 5 秒内弹出「允许连接」，加密与安全码不变；配对码保留。需部署新版服务器 |
| 2.3 | 官方 AI 额度：默认可用，自带 API Key 作为高级选项 | 第一步完成：工作坊与三个 AI 体验在没填自己 Key、但登录了账号时走官方通道（智谱 glm-4.5-air，每账号每月 30 次，失败不计；提交任务后轮询，不受 nginx 30 秒限制）。机器人对话（每月 300 次）、语音转写与朗读（每月 1500 次）经服务器的智谱兼容代理流式透传，机器人与语音代码不改；自带文字 Key 和语音 Key 分别生效。需部署新版服务器并写入 `/etc/atom/ai.env` |
| 2.4 | 首次开机引导 | 完成：欢迎 → 网络（能连上 ATOM 服务才算联网）→ 登录或注册 → 恢复密钥 → AI 状态 → 连接电脑 → 按键提示；未登录的设备首次开机出现一次，每步可跳过，可在「设置 → 系统工具」重开。待做：网络一步接上 3.1 的 Wi‑Fi 设置；手机扫码登录 |
