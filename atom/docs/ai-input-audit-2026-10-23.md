# AI 能力与通用语音输入核验 · 2026-10-23

## 实现范围

灰板 48 个安装应用的 HTML 由 server.py 注入 input-navigation.js；系统页面与工作坊预览使用同一运行时。普通输入框长按中心键/空格 650ms 开始，松手结束并转写，通过 input 事件写入草稿，不自动提交。密码和只读框不录音。超长、目标已销毁或手动修改后不覆盖，保留完整转写。邮箱无 selection API 时追加，contenteditable 支持选区与无选区回退。

已检查文本入口：随手记、今日、我的电脑、工作坊、相册、机器人、共生世界、语言炼金、合奏伙伴、月亮来信、天气之窗、指尖烟花、星盘密语、应用市场。日期格式等字段仍遵循自身格式校验，不把自由口述猜成日期。应用不需要各自配置 ASR Key。

## 本次真实验证

- 灰板 API 提交 world、visual、duet 三个独立的测试提示，均 completed，模型结果通过服务器结构校验；未覆盖用户作品。
- 灰板读取当前服务实际配置，通过官方语音通道 TTS 生成“这是语音输入功能测试。”，3.91 秒 WAV，再交由 ASR，返回“这是语音输入功能测试”。测试音频临时文件已删除，无扬声器播放和麦克风采集。
- 因此这是 TTS→ASR 网络链路验证，不是本轮环境噪声或麦克风声学验收。

## 自动化验证

input-navigation.integration 覆盖 text/search/url/tel/email/textarea/contenteditable 的真实键盘长按、选区插入、超长保留、密码排除、失效目标保护。joystick-shell.integration 覆盖实际 shell 与不透明 iframe 的录音请求、慢启动后松手、转写写入与原页返回。模型、语音、输入规范单元测试通过。world/visual/official clients 浏览器测试覆盖真实 Canvas/WebGL/WebAudio、失败不覆盖作品、保存确认、离线同步和退出清理；接口数据为测试夹具。

## 能力边界

生图沿用相册既有 Seedream 接口；本轮没有重复付费生图。尚未发现通用 OCR/图像理解入口，不能宣称已接通。天气、星盘、音乐播放等不需模型的应用不强加模型调用。机器人真实对话及用户环境下逐个录音输入需区分于以上 API/自动化验证，不能据此宣称全部手工验收完成。
