# 面向普通人的创作与应用社区

目标：在 Mac 和 ATOM 上完成「发现 → 体验 → 改成我的 → 安装 → 分享 → 向原作贡献」，不要求理解 Git、终端或源码文件。保留高级源码入口和既有数据兼容。

## 交付顺序与验收

1. **共同的数据流程**：私人草稿、不可变公开版本、来源关系、改进建议。建议必须由原作者预览并明确采用；上游已变化时拒绝覆盖。重复提交不创建重复草稿、建议或版本。
2. **发现与体验**：最新作品、大家的改造、分类与搜索；真实截图，一屏预览一个应用，前后切换。切换/退出停止旧预览，不自动安装，不虚构热度或使用量。
3. **两端创作**：一句话创建或修改，真实任务状态，可重试读取，原稿保留。官方 AI 为普通入口；Mac 原有 Agent/源码工作台作为高级入口。两端读取同一账号草稿。
4. **安装与发布**：预览后明确安装；区分已保存、已同步、等待设备、已安装、已发布。公开前确认标题/简介、真实首页截图、授权与源码隐私；包内不包含运行时用户数据。
5. **贡献循环**：「改成我的」保留独立副本；「建议合入原作」提交不可变候选；原作者查看差异、预览后采用到私人草稿，再单独发布。反馈仅来自真实建议状态。
6. **验证与交付**：服务端账号隔离、旧版本并发冲突、重试幂等、许可和密钥检查；真实浏览器下 Mac 与 480×360 小屏完整流程、加载/离线/失败、五向返回、无整页滚动；构建和文档同步。真机和线上结果单独记录，不能用模拟测试代替。

## 第一版边界

- 不引入点赞刷榜、签到、虚构推荐或复杂个性化算法。先用明确的分类、时间和真实改造关系帮助发现。
- 来源/许可不因改造而丢失。外部完整 ZIP 和尚未适配五向的历史应用保留兼容入口，不冒充可直接改造的新格式。
- 不自动合并代码冲突、不自动发布、不自动升级覆盖私人修改；采用建议后仍须预览和发布确认。
- 首页封面先使用真实截图上传。自动截图必须能真实渲染、供用户检查并隔离私有数据后才能开放，不能生成假截图替代。
- 所有修改保持现有仓库未提交工作；本计划不授权公开发布用户作品或更改云存储资源。

## 用户操作路径

- **发现**：看实际首页截图 → 试一试 → 喜欢就安装，或点「改成我的」。切换作品释放旧预览。预览数据临时保存，不能宣称已经保存到设备。
- **创作**：输入一句想法（名字选填）→ AI 修改 → 体验 → 继续说要怎么改。服务失败时原稿保留；进度断网时重新读取，不自动重复消耗额度。
- **分享**：我的 → 作品 → 分享作品 → 上传真实首页截图 → 检查名字、简介、源码与许可 → 明确确认发布。两端都可以操作；高级编辑器的「首页截图」入口继续保留。
- **安装**：Mac 选择同账号的 ATOM 或模拟器；设备选本机。离线设备保留排队状态，动态页显示真实安装回执。账号不同不会跨账号列出设备。
- **共同改进**：改成我的 → 修改 → 建议合入原作 → 作者预览 / 查看差异 → 采用到独立审阅草稿 → 再确认发布。采用不会覆盖作者已有未发布修改，也不会自动公开。
- **官方原作**：目前没有配置官方审阅账号的种子作品不显示提交建议按钮；可以独立改造并发布衍生版本。普通注册作者的建议闭环已经实现。

## 简单易用的后续约束

- 小电脑优先体验与使用，Mac 方便创作与管理；两端共享词汇和作品状态。功能入口数量不作为完成度指标。
- 设备根页面保留四个导航入口并明确标出当前位置；Mac 使用现有侧栏，不在内容区重复设备导航。进入具体任务保留集成标题与返回；源码、版本恢复、撤回和给作者的建议放在「更多操作」。
- 创作只要求一句想法，名字选填，之后仍可修改；未提交的修改想法在查看预览或更多操作后保留，切换账号时清除。
- 安装后直接提供「查看安装进度」，仍以真实设备回执为准。公开源码、权限和删除等重要选择继续明确说明。
- 480×360 的创作主按钮必须在首屏内，列表和长内容才使用局部滚动；保留鼠标和五向操作。
- 后台沿用既有 `ops.py overview`，用只读检查说明状态、容量及下一步，不另外建立一套管理服务。总览不冒充全链路健康证明。

## 实现与兼容

- `connect/marketplace/community.py`：幂等操作、生成任务、源码历史和建议；`creation_prompt.py` 统一引用 `static/app-input-standard.json`。
- `connect/relay/app_delivery.py` / `community_install.py`：账号隔离的完整源码快照配送；失败保留原应用；同收据重试不重复更新。
- `connect/computer/community.js` 是共享 UI 源；运行 `python3 atom/market-app/build.py` 同步设备包、预览和五向运行时，随后运行 `python3 atom/tools/prepare_icon_bundles.py`。
- 公共版本不变；草稿保存/生成/上传封面带 revision；多个作者审阅草稿发布带原作 head 检查；同时改了同一个文件时拒绝自动合并。
- 应用包上限 1984 KiB，传输总请求 2 MiB。超过 32 KiB 的单文件资源不提交给模型，修改时原样保留；完整资源 ZIP 仍走兼容目录，尚未统一到新改造格式。
- 模型调用仍使用已有官方额度。第一版没有个性化推荐、关注通知、评论排行或离线 AI；没有把这些写成已交付功能。
- 发布前必须由用户检查源码与真实截图；静态密钥扫描和五向声明只能拦截常见错误，不能证明应用运行效果或源码绝对安全。
