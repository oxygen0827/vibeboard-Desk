## 交付内容

- 扫码：设备生成 → 手机核对确认码并登录 → WebCrypto 解开并转交加密密钥 → 设备保存账号 → 自动继续引导。重复批准/领取安全重试；转交需要独立确认凭据；取消与超时撤销未领取会话；旧页面响应不写入新引导。
- 数据：AtomApp 读取先等待恢复判断，保存串行落盘再确认；写入失败保留旧值；旧 iframe 不接收新会话的回执。设备副本和前一版本均校验内容摘要。自动备份失败单独提示，不把成功的本机写入误报成失败。
- 系统：蓝牙命令退出码为 0 但实际失败时也显示错误；扫描与列表有边界；需输入配对码的设备提示使用 Debian 设置。电源操作要求确认，更新中禁止执行。模拟器禁止修改宿主电脑的电源、时区和蓝牙。
- 界面：时间、蓝牙、电源页面在 480×360 内布局，只有蓝牙列表滚动；当前时间按所选时区显示。
- 模拟器：任何资源变化都会刷新，更新保留原安装时间，避免桌面顺序变化；退休应用不加入新种子包。
- 依赖：本地二维码生成器固定 qrcode-generator 1.4.4，与 npm 原文件 SHA-256 一致，包含 MIT 许可和来源说明；不使用外部二维码生成服务。
