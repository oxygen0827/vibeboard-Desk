# 设备端应用工坊与主题

打开桌面上的工作坊，录音或输入应用需求，选择主题并生成。生成结果在隔离预览中运行，确认后点击安装到桌面。安装不会自动开启开发模式，也不会执行系统命令；应用仍遵守原来的 Web 应用限制。

首次使用需要配置生成模型的厂商、API 地址、模型名和密钥。DeepSeek 默认使用官方当前别名 deepseek-flash；其余厂商的具体模型按账户权限填写。兼容协议提供 DeepSeek、OpenAI、Qwen、MiniMax、Moonshot、Gemini、自定义入口；Anthropic 使用独立 Messages 适配。厂商账户与网络可用性未完成真实在线验收。

语音识别独立配置：OpenAI 兼容 audio/transcriptions 的 HTTPS Base URL、转写模型、密钥。设备不要求使用与生成模型相同的厂商。录音仅在用户点击后进行，最多30秒，停止后可转写、修改文字再生成。自动停止后显示转写入口。有效短录已验证；当前没有真实转写密钥，未验证语音识别准确性。成功转写后删除原录音，失败时保留可重试文件。

密钥只写入设备 state/model.json，权限0600，HTTP查询不返回密钥。更换API厂商或地址不会把旧密钥自动发送给新服务，需要重新填写。空密钥仅在同一服务下保持旧值，明确清除选项可以删除。不要把state/model.json打包上传或提交Git。

生成任务排队、调用、结构检查、预览分别有明确状态。90秒请求超时；失败不回显模型服务的响应体。生成代码只做结构检查，不保证需求正确，预览与真实交互验证仍然必要。任务暂存内存，设备服务重启后清空；安装的应用不受影响。

## 本地主题库

当前系统提供白天/暗黑外观与本地主题包导入，选择持久保存。主题可提供校验后的 icons 令牌及逐应用 overrides；应用语义 SVG 跟随主题渲染。早期四套配色不再作为当前内置清单。源码应用市场与账号已上线，联网主题市场尚未交付。详见 [系统外观](system-appearance.md) 与 [研发基线](current-status.md)。

主题包格式：

```json
{
  "manifest": {"id":"my-theme","name":"我的主题","description":"主题说明"},
  "tokens": {"bg":"#f3f0e8","ink":"#242622","accent":"#df5038","action":"#b53c28","muted":"#62665d","line":"#d5d3c8","card":"#ebe8df"}
}
```

颜色只允许六位HEX，不允许任意CSS或代码。官方ID不能覆盖，用户ID可更新。普通安装应用默认跟随设备主题的变量；工坊生成作品保存创作时选择的主题。应用使用固定颜色或自己的画面时不强制改写，创意应用可以保留视觉表达。

## 验证记录

设备端25项测试通过，覆盖模拟模型生成、结构检查、用户确认安装、主题冻结与无密钥提示。四主题切换、刷新恢复及界面输入在真机浏览器验证。真实生成与转写需要用户在配置界面接入API后再完成验收；本轮没有调用收费模型。

协议参考：[DeepSeek首次调用](https://api-docs.deepseek.com/en/)、[OpenAI文件转写](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create)。
