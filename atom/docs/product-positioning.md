# ATOM 产品定位

更新：2026-10-23。实现范围与待验收事项统一见 [当前研发基线](current-status.md)。

一句话：一台以语音为入口、让用户创造并运行个人小应用的独立桌面AI终端。

用户价值：把“我想要一个这样的工具”缩短为“说出需求、生成预览、安装到桌面、重复使用”。独立设备让工具、互动内容和提示有固定的桌面位置；用户可以按自己的用途塑造它。普通用户通过语音与工作坊创作，开发者通过开放Web应用、SDK和开源移植扩展。

当前交付是基于Linux的系统体验层和可交互工程样机：有统一桌面、全屏应用、长按管理、应用生成预览安装、独立保存、语音转写与朗读。小应用在设备上运行；模型生成与ASR/TTS依赖云端服务。可视化和表情应用验证显示与图形能力，但长期使用价值仍需精品应用与持续使用验证。

跨端价值：电脑通过 ATOM Connect 管理授权项目和 Agent 任务，云端承载账号、中继、同步及完整源码市场；小电脑保持独立应用运行。用户可以基于公开源码改造、再发布，设备不需要承担电脑开发环境或大型本地推理。

边界：当前仍是工程原型，真实摇杆、旧应用逐项适配、长期稳定性和正式发行需继续验收。不能把接口实现等同于成熟消费级系统。

下一阶段优先级：生成质量与可靠恢复、少量每天愿意使用的精品应用、低延迟语音和声学硬件、应用与设备的长期稳定性。建立模型API之外的持续产品价值：可积累的个人应用和数据、统一交互、真实硬件能力，以及可扩展的开发规范。

桌面管理：图标左键按住600ms打开操作菜单；短按打开；移动超过10px取消长按；拖动翻页继续保留。内置应用禁止卸载，安装应用二次确认卸载，当前卸载删除应用文件并保留应用数据。失败显示错误并允许重试。真机测试使用临时应用，原有应用与顺序保留。
