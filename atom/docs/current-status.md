# 当前研发基线与验收边界

更新：2026-10-23。本文件维护当前状态；具体接口以相应契约为准，历史测试数字不代表持续通过证明。

| 部分 | 已交付基线 |

安装目录数、静态目录数、市场作品数和源码库数不是同一指标。市场普通发布版本与完整资源 `library` 分开；历史停用的云朵伙伴、任务伙伴不重新发布。公开资源不自动覆盖用户已安装应用，更不会自动公开私人创作。公共核心 latest 没有随灰板定向升级推进。

## 当前交互

四向移动焦点，Space 短按确认、长按约 650 ms 唤醒语音或输入框听写，松手结束；Home 回桌面，在桌面再按回首页。左上角箭头逐层返回。共享运行时提供选框动画，鼠标模式与方向输入模式切换；应用无常驻系统栏。桌面三列两行，应用优先、上下同列、跨页同行，首末页有边界回弹。

应用必须遵守 [input-standard.md](input-standard.md)；设备工作坊与 Mac 创建/改造共用机器规范。旧应用兼容运行不等于逐项适配，不能自动补声明。语音接口已有真实云端调用验证；灰板本轮五向测试验证了录音开始、取消、风扇恢复，没有证明真实人声听写准确率。

## 已验证的主要链路

- 设备 → 云端 → Mac Codex → 设备：真实任务往返，保留审批、取消和会话权限边界。
- 核心签名下载与安装、失败恢复隔离测试；灰板定向升级保留应用和身份。
- AtomApp 保存等待落盘确认、读取失败不覆盖旧数据；模拟器种子更新保留安装时间与顺序。
- 手机登录/注册的 WebCrypto 与密钥交付在隔离浏览器完成；真实账号没有被测试身份覆盖。
- 源码库全部 62 个 ZIP 发布前检查摘要、路径、文件数；公网大小核对、实际下载及 Mac/官网获取验证。详细测试与证据见[完整同步记录](full-library-sync-2026-10-23.md)。
- 最近九个生活/探索应用的界面、语义操作、持久化和灰板浏览器流程有对应记录：[生活应用](life-apps-delivery-2026-10-23.md)、[探索应用](oracle-apps-2026-10-23.md)。

实机证据保留于 [五向导航](../artifacts/joystick-20261022/)、[系统维护](../artifacts/system-completion-20261022/)、[全量同步](../artifacts/full-library-covers/)。删除重复阶段文档不删除这些验证材料；旧版原文仍可通过 Git 历史追溯。

## 后续验收与发行条件

1. 接入真实五向摇杆，验证抖动、按住/松开、文本听写；旧应用逐个补齐画布操作与内部返回，不能以静态校验代替动态检查。
2. 准备明确授权的蓝牙耳机/音箱，验证配对、出声、断开与重连；现有私有 D-Bus 和界面测试不代表实物兼容。
3. 在人在场、有恢复通道时测试第二条 Wi-Fi、错误密码及恢复旧网络；不为测试清除现有网络。
4. 使用隔离账号走真实手机扫码开箱，补正常重启、关机再开机、冷启动及长期负载；不清空用户数据冒充开箱验收。
5. 旧 BSP Xorg/显示等待根因尚未修复；守护不再自动热重启 LightDM。灰板可选显示守护保持停用，避免把危险恢复当作稳定性修复。
6. Apple Developer ID、正式签名公证、SMTP 待配置；当前 Mac 只能视为内部测试包。Windows 原生安装包和联网主题市场未交付。
7. 相册原图与 HEIF 导入成功不等于生图模型已开通；按[相册说明](../official/photo-album/README.md)核对供应商权限及实际调用结果。
8. Debian 10 / Chromium 91 为旧 BSP 原型，需维护升级、安全评估、低内存硬件与长期运行验证。没有把 NPU 示例执行等同于本地 ASR/OCR 产品交付。

## 运维约束

只升级需要的组件；不覆盖 `apps/`、`state/`、配对和模型配置。例行维护优先检查现有可用备份。阿里云数据库本地归档和 OSS 对应归档各保留三份，完成新归档后才清理旧归档；不自动创建 ECS 快照/自定义镜像或启用 OSS 版本管理。源码库只清理工具管理、已校验可替代的旧资源，详见 [AGENTS.md](../../AGENTS.md) 与[服务器说明](../connect/server/README.md)。
