# 随手记

独立设备应用 `quick-notes`，与电脑工作台通过同一市场账号同步纯文字笔记。支持置顶、回收站、恢复、长按语音追加草稿。语音不会自动提交笔记。

## 离线与保存

- 编辑草稿通过 AtomApp ACK 保存在本机；点击「保存笔记」才加入上传队列。
- 每条最多 4000 字，本机持久缓存总预算 55 KiB、最多 12 条。优先保留未同步记录，缓存不足时明确阻止保存，不自动删除未同步原文。
- 更多云端笔记可以联网查看，未持久缓存的条目标明「联网可用，未离线缓存」。
- 客户端随机笔记 ID 加 revision 0 支持断网新建后幂等上传。已有笔记使用乐观版本，409 不静默覆盖。
- 冲突可重新获取比较，明确选择「保留两份」或「采用云端」。保留两份会将本机原文另存为新 ID，保留云端原记录。
- 同步请求按 edit_stamp 对比，旧 ACK 不会清除后续编辑的 pending；更新后续修改的基线 revision。

## 账号隔离

本机记录按 `user.id` 分桶，不会把上个账号的离线修改发送到新账号。登出清空显示和内存云端列表，并回到独立的「本机离线」桶。切换后，旧账号未同步内容仍在其隔离桶内，重新登录原账号才能同步。未登录创建的本机记录不会自动导入任何账号。

无法核对服务身份时，先提示身份未确认；明确打开本机离线记录后可以继续查看/编辑，但绝不上传，直到重连核对相同账号。该隔离是应用行为，不宣称共享设备上的加密保密存储。

安装包、桥协议、浏览器测试见 `../market-app/README.md` 和 `../connect/PRODUCT-CONTRACT.md`。
